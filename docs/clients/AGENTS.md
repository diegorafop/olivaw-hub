# Diretrizes — Clientes

- Centralize cada cliente em sua própria pasta, com `README.md` como índice.
- Guarde estudos e ideias livres em `brainstorm/`, especificações em `features/`, evidências e acervo em pastas descritivas. Não crie features fictícias para preencher estados.
- As features seguem os quatro blocos e estados definidos em [features/AGENTS.md](../features/AGENTS.md). Consulte também o [guia Git Flow](../gitflow.md).
- O `features/index.md` de cada cliente lista apenas suas funcionalidades concluídas; mantenha o planejamento no README ou em plano próprio.
- Preserve feedback original, histórico datado, decisões, limites de validação e estados de implementação/publicação. Atualize links de entrada e saída ao mover arquivos.
- Não trate propostas como aprovação do cliente nem inclua segredos ou dados pessoais desnecessários.
- Mudanças de código continuam seguindo também as instruções do respectivo módulo.
