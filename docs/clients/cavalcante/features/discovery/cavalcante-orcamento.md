## acceptance-criteria

- Pedido informa serviço ou equipamento, bairro/cidade, data e descrição; campos adicionais só quando necessários.
- Validação acessível informa erro e preserva os dados durante correção.
- WhatsApp usa número aprovado e mensagem contextual; clique não equivale a pedido recebido.
- Formulário futuro apresenta confirmação somente após sucesso real, com estados de indisponibilidade.
- Definir dados pessoais mínimos, retenção, acesso e política de privacidade antes de persistir.

## ai-prompt

Proposta futura. Nesta entrega, somente links de WhatsApp, sem formulário ou envio automático. Confirmar quem atende, dados indispensáveis, SLA e necessidade de anexos. Persistência, notificações e API exigem nova etapa autorizada. Não contatar terceiros durante testes.
