## Orçamentos de desenvolvimento

Cada anúncio analisado recebe uma pasta pelo identificador. Objetivo: entender o problema, estimar investimento e preparar uma proposta de programação e uma abordagem para apresentar a Olivaw.

### Roteiro para os próximos casos

Use o [padrão documental superior](../features/AGENTS.md) e as [orientações para IAs](AGENTS.md).

1. Registrar anúncio, referência, origem, fatos e dúvidas no diretório do orçamento.
2. Produzir `analise.md`, `estimativa.md` e `abordagem.md`, com requisitos, alternativas de plugins, lacunas e horas por profissional.
3. Comparar implementação avulsa e continuidade Olivaw, explicitando condições ainda não aprovadas.
4. Preparar os JSONs de cadastro e proposta conforme os contratos da aplicação.
5. Após publicação e autorização, importar no painel de Leads, revisar e salvar; gerar a apresentação HTML ao final, no design system da Olivaw.

Acompanhe o estado técnico pelo padrão superior. Registre separadamente a situação comercial, com data e evidência. O caso 795293 é rascunho e ainda não foi enviado ou cadastrado.
