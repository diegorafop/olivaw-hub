# Cavalcante — Site de serviços e catálogo de máquinas

## Título para o 99Freelas

Cavalcante — Site de serviços e catálogo de máquinas

## Descrição para o 99Freelas

Site responsivo desenvolvido para a Cavalcante divulgar seus serviços de terraplenagem e locação de máquinas. Reúne catálogo de equipamentos com filtros, apresentação da empresa e informações sobre os serviços prestados, com navegação adaptada para computadores e celulares.
