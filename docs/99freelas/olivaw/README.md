# Portfólio para o 99Freelas

## Título

Olivaw Hub — Site institucional e estúdio interativo

## Descrição

O Olivaw Hub reúne site institucional e um estúdio interativo para explorar ideias de sites e sistemas. Projeto próprio com atuação em desenvolvimento full stack, arquitetura de software, infraestrutura e DevOps, pensado para apresentar soluções simples e adaptadas às necessidades de pequenos e médios negócios.
