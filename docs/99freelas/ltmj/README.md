# LTMJ Eventos — Site com gestão de eventos

## Título para o 99Freelas

LTMJ Eventos — Site com gestão de eventos

## Descrição para o 99Freelas

Site responsivo para a LTMJ apresentar seus serviços e divulgar eventos realizados. Inclui área administrativa para os responsáveis cadastrarem e editarem eventos, adicionarem fotos e controlarem o que aparece no site. A solução permite à própria equipe manter o portfólio atualizado, inclusive pelo celular.

## Imagens

Cinco capturas da execução local em 30/10/2026, com 1500 × 1002 pixels, na proporção de 250 × 167. Use `01-apresentacao-desktop.png` como capa. A imagem de celular usa margens para preservar a proporção original. Contatos e links de redes sociais foram ocultados nas capturas.

## Observações internas

As capturas da gestão e do mural usam um cadastro demonstrativo com foto do acervo do projeto. A autenticação e os contratos HTTP foram simulados localmente, sem acesso a contas ou bancos reais.
