# Olivaw Hub

Tecnologia e inteligência para pequenos negócios.

Olivaw Hub é o nome escolhido para o projeto, anteriormente chamado Easy Cloud. A marca faz referência a R. Daneel Olivaw, personagem da literatura de Isaac Asimov.

O contexto inicial, a proposta de negócio e a direção técnica estão registrados em [BRIEFING.md](BRIEFING.md).

O projeto está na fase inicial de definição. As tecnologias mencionadas no briefing representam a intenção inicial, não uma implementação existente.
