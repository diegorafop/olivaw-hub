# Diretrizes — Ferramentas dos agentes

- Instalador de skill copia apenas a skill canônica revisada, preserva outras skills e recusa links ou destino inesperado.
- Escrever em ~/.agents/skills somente por solicitação explícita de instalação do mantenedor.
- Não invocar IA, SSH ou serviços durante instalação. Nunca promover a pasta de proposta como se fosse fonte revisada.
